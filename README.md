# Meu Portfólio - Programa Trilhas Inova 🚀

Um portfólio pessoal desenvolvido com foco em apresentar minhas habilidades, projetos e trajetória como Desenvolvedor Front-end, construído e aprimorado como parte da minha evolução no Programa Trilhas Inova.

## Sobre o Projeto

Este projeto foi criado do zero utilizando as melhores práticas de estruturação e estilização web. 
O objetivo é servir como um cartão de visitas digital, onde compartilho um pouco sobre mim (minha jornada na Ciência da Computação, vivências de mercado e hobbies) . 
Meus links profissionais e a vitrine de projetos que venho desenvolvendo.

##  Tecnologias Utilizadas

- **HTML5:** Estruturação semântica.
- **CSS3:** Estilização utilizando Flexbox, CSS Grid para a seção de projetos e transições suaves (hover effects) para uma melhor experiência de usuário.
- **Design Web:** Prototipação e princípios de UI/UX.

##  Funcionalidades

- **Apresentação:** Perfil centralizado com links de contato rápido.
- **Sobre Mim:** Um resumo sobre minha trajetória profissional e acadêmica.
- **Meus Projetos:** Exibição dos meus trabalhos em formato de grade interativa.
